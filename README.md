# **🧠 AutiScan**
Machine Learning-Based Autism Risk Screening Web Application

AutiScan is a machine learning-powered web application designed to provide an initial autism risk screening based on user-provided assessment information.

The project combines a machine learning workflow with a Django web application, allowing users to enter relevant information through a web interface and receive a model-generated screening result.

⚠️ Disclaimer: AutiScan is an educational and technical project. It is not a medical diagnostic tool and should not be used as a substitute for assessment or advice from qualified healthcare professionals.

## **📌 About the Project**

AutiScan was developed to explore how machine learning can be integrated into a practical web application.

The project covers an end-to-end workflow:

User Input → Data Processing → ML Model → Prediction → Web Result

The application provides a simple interface for collecting assessment information and presenting the resulting prediction in an accessible format.

### **⚙️ How It Works**
1. 📝 User Input

&nbsp;&nbsp;&nbsp;&nbsp;The user provides the required assessment information through the web interface.

2. 🔄 Data Processing

&nbsp;&nbsp;&nbsp;&nbsp;The submitted information is processed into the format required by the machine learning model.

3. 🤖 Model Prediction

&nbsp;&nbsp;&nbsp;&nbsp;The trained machine learning model analyzes the processed input and generates a prediction.

4. 📊 Result

&nbsp;&nbsp;&nbsp;&nbsp;The prediction is returned to the Django application and presented to the user.

### 🚀 Getting Started
Prerequisites

Make sure you have the following installed:

-Python 3.x

-pip

-Git

1. Clone the Repository<br>

&nbsp;&nbsp;&nbsp;&nbsp;`git clone https://github.com/sumukh-bhat-04/AutiScan.git`<br>

&nbsp;&nbsp;&nbsp;&nbsp;`cd AutiScan`

2. Create a Virtual Environment

Windows

`python -m venv venv`<br>

`venv\Scripts\activate`


macOS / Linux

`python -m venv venv`<br>

`source venv/bin/activate`

3. Install Dependencies<br>

`pip install -r requirement.txt`

4. Run the Django Application<br>

`python manage.py runserver`


Open the local development server displayed in your terminal to access the application.
